🐳 Trilha Docker

Repositório criado para documentar minha jornada de estudos em Docker, reunindo anotações, exercícios, exemplos práticos e projetos desenvolvidos durante o aprendizado da tecnologia.

O objetivo deste repositório é servir como material de consulta e registrar minha evolução no uso de containers para desenvolvimento, testes e implantação de aplicações.

📚 Conteúdo

Durante esta trilha serão abordados os seguintes tópicos:

Introdução ao Docker
Containers e Imagens
Docker Hub
Principais comandos do Docker
Criação de imagens com Dockerfile
Gerenciamento de volumes
Redes (Networks)
Variáveis de ambiente
Docker Compose
Orquestração de múltiplos containers
Persistência de dados
Boas práticas na criação de imagens
Projetos práticos utilizando Docker
